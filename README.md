# 👗 DressStyle AI

Live Demo : https://dressstyle-ai-kc4uhg6miccojnsscygsrz.streamlit.app/

DressStyle AI is an AI-powered fashion recommendation and dress styling application built using Python and Streamlit.

The application helps users explore fashion styles, get personalized dress recommendations, analyze dress images, search for dresses, compare options, discover deals, and save favorite items.

## ✨ Features

### 🏠 Home
A modern homepage that introduces the main features of DressStyle AI.

### ✨ AI Fashion Stylist
Get personalized dress recommendations based on:

- Occasion
- Preferred colour
- Fashion style
- Dress type
- Budget

### 📸 Virtual Try-On
Upload fashion-related images and explore AI-powered outfit analysis and styling features.

### 🔍 Dress Search
Search for dresses based on colours, styles, and preferences.

### 💰 Price Comparison
Compare available dress-shopping options based on the user's search and budget.

### 🔥 Best Deals
Explore available fashion deals and budget-friendly options.

### ❤️ Wishlist
Save favorite dresses and fashion items for later.

### 🤖 AI Image Analysis
DressStyle AI can analyze uploaded outfit images and provide information such as:

- Outfit type
- Main colours
- Pattern and design
- Fashion style
- Styling suggestions
- Search keywords

## 🛠️ Technologies Used

- Python
- Streamlit
- Ollama
- Qwen Vision Model
- PIL (Python Imaging Library)
- Requests
- python-dotenv
